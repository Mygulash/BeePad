# 🐝BeePad
Hackpad project from Hack Club

Beepad is a macropad with 9 switches, rotary encoder and OLED display. It runs KMK firmware. 
***
## Features: 
- 9 keys
- 128×32 OLED display
- Rotary encoder
***
## CAD model
Everything fits together using 6 M3 bolts and heat-set inserts.

It consists of 2 printed parts: 
- Top
- Bottom

## BOM:
- 9x Cherry MX Switches
- 9x DSA Keycaps
- 6x M3x5x4 Heatset inserts
- 6x M3x16mm SHCS Bolts
- 9x 1N4148 DO-35 Diodes.
- 1x 0.91" 128x32 OLED Display
- 1x EC11 Rotary Encoder
- 1x XIAO RP2040
- 1x Case (2 printed parts)
